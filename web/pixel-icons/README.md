# Pixel icons drop folder

Download retro-pixel SVGs from https://www.svgrepo.com/collection/retro-pixel-icons/
and save them here using EXACTLY these filenames (one per app icon, `<name>.svg`).
Any name missing a file keeps the current stroke icon as fallback — so a
partial set still works.

## Navigation (sidebar)
- `ask.svg` — chat / speech bubble
- `corpus.svg` — stacked layers / database / archive
- `measurements.svg` — bar chart

## Workspace menu
- `database.svg` — database / server
- `chevronDown.svg` — pixel arrow down
- `chevronRight.svg` — pixel arrow right
- `plus.svg` — plus
- `settings.svg` — gear / sliders

## Actions
- `search.svg` — magnifier
- `menu.svg` — hamburger (3 bars)
- `upload.svg` — arrow up out of tray
- `copy.svg` — two overlapping squares
- `refresh.svg` — circular arrow / reload
- `link.svg` — chain link
- `trash.svg` — bin
- `play.svg` — right-pointing triangle
- `stop.svg` — square
- `history.svg` — clock with arrow
- `x.svg` — close cross
- `check.svg` — tick

## Status / outcomes
- `checkCircle.svg` — tick in circle/square
- `xCircle.svg` — cross in circle/square
- `alertTriangle.svg` — warning triangle
- `alertCircle.svg` — exclamation in circle
- `info.svg` — lowercase "i"
- `searchMinus.svg` — magnifier with minus
- `shield.svg` — shield
- `dot.svg` — tiny square/dot (any small square works)

## Misc
- `file.svg` — document/page
- `help.svg` — question mark
- `sun.svg` — sun (light theme)
- `moon.svg` — moon (dark theme)
- `command.svg` — theme "system" option (any neutral glyph)

## Notes
- Prefer the monochrome versions so they inherit `currentColor`.
- Check the license shown on each file's svgrepo page (most are MIT/CC0;
  keep attribution if required).
- Pixel icons render with `shape-rendering: crispEdges`; odd sizes are
  snapped to whole pixels in code, no action needed here.
